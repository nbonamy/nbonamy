### Working with Agents

I build with agents every day, and Korus and Skwad are where I figure out how to do it well.

- **Orchestrating teams of agents** — running several coding agents in parallel on the same codebase, each with its own role and context
- **Agent-ready workflows** — worktrees, tests, and reviews that let agents move fast without breaking things
- **Tools and protocols agents rely on** — MCP servers and clients, multi-provider LLM abstractions
- **Language-agnostic shipping** — TypeScript, Swift, Python, Flutter: I pick what fits the product and let agents handle the syntax
